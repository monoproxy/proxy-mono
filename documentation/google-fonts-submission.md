# Google Fonts submission: Proxy Mono

Draft of the "Add a new font family" issue for github.com/google/fonts. Not yet filed.

**Title:** Add Proxy Mono

**Repository:** https://github.com/monoproxy/proxy-mono
**Licence:** SIL Open Font License 1.1 (derivative of Space Mono, Martian Mono and Geist Mono, all OFL, no Reserved Font Names)
**Designer:** monoproxy
**Axes:** wght 100–900
**Glyph set:** GF Latin Core (571 characters)

## Description

Proxy Mono is a monospaced typeface in nine weights, from Thin to Black, made by monoproxy, a Sydney studio that builds and teaches.

Every character sits on the same 700-unit cell and carries the same stroke weight at each weight, so columns of code, tables and receipts line up and read evenly. Capitals are wide and square-shouldered, the zero is slashed, and there are no ink traps. Proxy Mono is a remix of open-source monospaces, reworked so that capitals, lowercase and figures share one stroke.

It covers GF Latin Core and more: Western, Central and Eastern European languages, Vietnamese, and a wide set of symbols, arrows and currencies.

To contribute, see github.com/monoproxy/proxy-mono.

## QA

`make gfstage` lays the family out as google/fonts does (`out/gf/proxymono/`: font, METADATA.pb, OFL.txt,
article). FontBakery `check-googlefonts proxymono/ProxyMono[wght].ttf`: **0 FAIL, 4 WARN** (was 11).

What remains, and why:
- designer_profiles: monoproxy isn't in the Google Fonts designer catalogue yet. The onboarding PR
  adds it; it needs a bio, a link and a square photo or logo.
- unreachable_subsetting: the combining marks (U+0306, 030A, 030B, 030C, 031B, 0328, 0335-0337) belong
  to no Google Fonts subset, but shape_languages *fails* (Czech, Danish, Vietnamese) without them. The
  two checks conflict; we keep the marks.
- shape_languages: Ʒ ʒ Ǯ ǯ (Skolt Sami, under Finnish) and Ĳ ĳ (Dutch) are auxiliary only. They need
  drawing; assembled versions were tried and rejected.
- vendor_id: register MNPX with Microsoft (https://learn.microsoft.com/en-us/typography/vendors/).

## Build

The fonts are generated by Python (`sources/generator/az.py` and `vf.py`) from the upstream fonts in `sources/upstream/`. There is no gftools-builder `config.yaml`. Google Fonts may ask for buildable sources (.glyphs, .ufo or .designspace). If they do, export the nine masters as UFOs plus a designspace.
